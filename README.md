# CreatorAudit

CreatorAudit is an AI-powered content analysis tool designed to evaluate social media creators and generate detailed performance reports.

The project analyzes creator profiles, content patterns, and engagement characteristics to provide actionable insights through automated reports and visualizations.

## Features

* Creator profile analysis
* Content evaluation and scoring
* AI-generated insights and recommendations
* Automated report generation
* Interactive visualizations and radar charts
* Downloadable reports

## Technologies Used

* Python
* Flask
* HTML/CSS
* JavaScript
* AI-powered text generation
* Data visualization

## Project Structure

```text
app.py                - Main application
analyzer.py           - Content analysis engine
ai_writer.py          - AI insight generation
report_generator.py   - Report creation system
templates/            - Frontend templates
attached_assets/      - Project assets
```
